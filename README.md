# Task 5: Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset. The objective is to explore the dataset, identify patterns and relationships, detect missing values and potential outliers, and extract meaningful insights using statistical analysis and data visualization.

## 🎯 Objective

- Understand the structure and characteristics of the dataset.
- Identify missing values and duplicate records.
- Analyze numerical and categorical variables.
- Explore relationships between passenger characteristics and survival.
- Identify trends, patterns, and potential outliers.
- Present findings through meaningful visualizations.

## 🛠️ Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

The following analyses were performed:

- Dataset structure and descriptive statistics
- Missing value analysis
- Gender distribution
- Survival analysis
- Survival by gender
- Survival by passenger class
- Age distribution
- Fare distribution
- Boxplot analysis
- Correlation heatmap
- Pairplot analysis
- Age group analysis
- Survival rate analysis
- Multivariate analysis

## 🔍 Key Findings

- Female passengers had a higher survival rate than male passengers.
- First Class passengers generally had higher survival rates.
- Third Class passengers had lower survival rates compared with higher classes.
- The dataset contains missing values, particularly in the Deck and Age columns.
- Fare contains some potential outliers.
- Gender and passenger class showed important relationships with survival outcomes.
